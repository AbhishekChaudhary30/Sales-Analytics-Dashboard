# Sample Sales Datasets

This directory provides bundled sample sales datasets for immediate demonstration, automated tests, and offline exploration.

## Included Files

### `superstore_sample.csv`
- **Rows**: 150 transactions
- **Columns**: 21 fields (Order ID, Order Date, Ship Date, Ship Mode, Customer ID, Customer Name, Segment, Country, City, State, Postal Code, Region, Product ID, Category, Sub-Category, Product Name, Sales, Quantity, Discount, Profit, Payment Method)
- **Time Span**: 2023 - 2024
- **License / Attribution**: Synthetically modeled after the Tableau Superstore retail schema for offline benchmarking without external API or internet dependencies.

## External Reference Datasets

For larger production-scale testing, consider these public sources:
1. **UCI Machine Learning Repository: Online Retail Dataset**
   - URL: https://archive.ics.uci.edu/dataset/352/online+retail
   - Content: ~540,000 transactions from a UK-based non-store online retail business.
   - Recommended Format: CSV / XLSX.
2. **Tableau Sample Superstore Data**
   - URL: https://www.tableau.com/learn/sample-data
   - Content: North American retail orders, returns, and people.
3. **Kaggle E-Commerce Sales Datasets**
   - URL: https://www.kaggle.com/datasets
   - Note: Download requires a free Kaggle account; save the resulting `.csv` file and upload via the app's upload interface.
