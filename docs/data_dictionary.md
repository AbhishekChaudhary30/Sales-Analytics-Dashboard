# Standard Sales Business Data Dictionary

The **Sales Analytics Dashboard** utilizes a flexible internal schema consisting of 22 standard business fields. When users upload heterogeneous sales datasets, the intelligent column-mapping engine maps detected attributes to these standardized keys.

---

## 1. Core Financial & Transaction Measures

| Standard Key | Display Name | Data Type | Essential? | Description | Sample Recognized Aliases |
| :--- | :--- | :--- | :---: | :--- | :--- |
| `sales` | Sales / Revenue | Numeric | **Yes** | Total monetary transaction revenue or gross sales. | `sales`, `revenue`, `sales_amount`, `total_sales`, `amount`, `gross_sales`, `turnover` |
| `order_date` | Order Date | Datetime | **Yes** | Date when the sales transaction occurred. | `order_date`, `order date`, `date`, `invoice_date`, `transaction_date`, `sale_date` |
| `order_id` | Order ID | ID / String | No | Unique identifier for orders or invoices. | `order_id`, `invoice_no`, `invoiceno`, `transaction_id`, `order_number`, `document_no` |
| `quantity` | Quantity | Numeric | No | Number of product units sold in the transaction. | `quantity`, `qty`, `units`, `units_sold`, `volume`, `order_quantity`, `item_count` |
| `unit_price` | Unit Price | Numeric | No | Selling price for a single unit. | `unit_price`, `price`, `rate`, `item_price`, `price_per_unit` |
| `cost` | Cost | Numeric | No | Cost of goods sold (COGS) or production cost. | `cost`, `cogs`, `cost_of_goods_sold`, `total_cost`, `purchase_cost`, `expense` |
| `profit` | Profit | Numeric | No | Net profit or gross margin generated by the sale. | `profit`, `net_profit`, `profit_amount`, `gross_profit`, `margin`, `earnings` |
| `discount` | Discount | Numeric | No | Markdown or discount rate applied (0.0 to 1.0 or %). | `discount`, `discount_amount`, `discount_rate`, `discount_pct`, `markdown`, `rebate` |

## 6. Unmapped Attributes Handling

Any raw dataset columns that are not mapped to one of the 22 standard fields are **never discarded**. They are automatically retained in the standardized DataFrame with an `unmapped_{column_name}` prefix, ensuring complete data preservation throughout the analytical session.
